# 이자이익 분석 워크스루

## 이 문서의 역할

[이자이익 분석 노트북](../notebooks/3.이자이익_분석.ipynb)은 해커톤 당시 세부 가설을 탐색한 기록입니다. 반복 정의와 셀 간 의존성이 남아 있어, 포트폴리오 독자는 이 문서를 먼저 읽고 필요할 때 원본 노트북을 보조 증빙으로 확인하는 흐름을 권장합니다.

## 질문

이자이익 트랙은 “대출 잔액이 큰 고객은 누구인가”보다 **대출 상품별로 어떤 고객 프로필과 잠재 수요가 나타나는가**를 묻습니다. 같은 캠페인을 전체 고객에게 적용하기보다, 상품·생애주기·거래 관계에 맞춰 관리 방향을 나누는 것이 목표였습니다.

## 읽는 순서

1. [분석 방법](analysis-method.md)에서 구간형 금융 데이터를 해석 가능한 형태로 바꾼 원칙을 확인합니다.
2. 이자이익 노트북에서 대출 보유 조합과 고객 특성을 비교한 탐색 과정을 확인합니다.
3. [결과 및 전략](results.md)의 서민전용대출 사례와 [최종 발표자료 23쪽](presentation-assets.md)에서 실행 제안으로 연결된 결과를 확인합니다.

## 공개본에서 보존한 판단

- 대출 상품별 고객 특성이 다르므로, 총 대출 규모 하나로 고객을 판단하지 않습니다.
- 서민전용대출은 20~30대 비중, 전세·신용대출 동시 보유, 가용 기간 특성을 조합해 잠재고객 발굴과 기존 고객 관리로 나눠 제안했습니다.
- 해당 수치와 전략은 실제 최종 발표자료의 23쪽을 기준으로 하며, 원본 고객 행이나 새로 생성한 차트는 공개하지 않습니다.

## 실행과 검증의 한계

원본 입력 `hacktho_FF_final.csv`가 공개 저장소에 없으므로, 이 노트북의 전체 재실행은 현재 보장하지 않습니다. 또한 공개본의 노트북은 실행 중 패키지 설치·인터넷 다운로드를 하지 않습니다. 재현 조건은 [재현 가이드](reproducibility.md)에서, 공개 범위는 [data/README.md](../data/README.md)에서 확인할 수 있습니다.
