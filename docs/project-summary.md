# 프로젝트 요약

## 한 줄 요약

BNK부산은행 고객 데이터를 이자이익과 비이자이익 관점으로 분리 해석해, 고객 세분화와 관리 전략을 함께 제안한 24시간 데이터 해커톤 프로젝트입니다.

## 과제와 문제 정의

2025년 8월 DIVE 글로벌 데이터 해커톤에서 BNK부산은행이 제시한 과제는 다음과 같았습니다.

> 거래 유형별로 BNK 고객유형을 분류하고 분석하여 관리방안을 제언하라.

팀은 고객을 하나의 군집 결과로만 정리하면 수익 목표가 다른 고객을 같은 기준으로 판단하게 된다고 보았습니다. 그래서 다음 두 질문으로 분석을 분리했습니다.

1. 안정적인 이자이익에 기여하는 고객은 누구인가?
2. 비이자이익 확장 가능성이 큰 고객은 누구인가?

## Two-track 분석

| 트랙 | 중심 변수 | 해석 목적 |
| --- | --- | --- |
| 이자이익 | 원화대출잔액, 대출 상품군 | 상품별 잠재고객과 안정적 수익 기반 파악 |
| 비이자이익 | 펀드·방카슈랑스 잔액, 신용·체크카드 거래액 | 비이자상품 확장 가능성과 성장 경로 파악 |

예금은 자금조달 측면에서 중요하지만, 이 프로젝트의 중심 질문인 수익 구조 다변화에 대한 직접성이 낮아 핵심 세분화 변수에서는 제외했습니다.

## 박민규의 기여

최종 발표자료의 역할 분담에 따라, 박민규는 **데이터 전처리 및 모델링**을 담당했습니다.

- 구간형 데이터를 수치형 대표값으로 변환
- 모순 데이터 제거를 포함한 데이터 정제
- K-Means 기반 고객 군집화 모델 구축
- 후속 비이자이익·이자이익 분석에서 사용할 분석용 데이터셋 구성
