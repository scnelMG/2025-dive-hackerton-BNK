# 공개 범위와 데이터 보호

## 공개하는 산출물

이 저장소에는 포트폴리오 검토에 필요한 아래 산출물만 포함합니다.

- 문제 정의와 분석 방법 문서
- 집계 수준의 결과·전략 문서
- 실제 최종 발표자료와 해당 슬라이드에서 추출한 README 이미지
- 전처리·군집화·수익 트랙 분석의 코드 흐름을 보여주는 노트북

## 공개하지 않는 자료

| 자료 | 제외 이유 |
| --- | --- |
| 고객 원천 CSV 및 전처리 파생 데이터 | 금융 고객 데이터로서 재배포·공개 범위를 확인할 수 없음 |
| 대회 발제 자료와 제공 문서 | 발제 기관 자료의 재배포 권한이 불명확함 |
| 제출 코드 ZIP과 중간 산출물 | 공개본의 핵심 흐름과 중복되거나 탐색 흔적을 포함함 |
| 외부 보관소의 Git 메타데이터 | 포트폴리오 검토에 필요하지 않고 공개 범위를 보장할 수 없음 |

## 공개본 편집 원칙

- 고객 단위 표와 긴 탐색 출력은 노트북에서 제거하고, 실제 분석 그래프와 집계 결과만 유지합니다.
- README 이미지에는 실제 최종 발표자료를 렌더링한 슬라이드만 사용합니다. 별도로 생성한 이미지는 사용하지 않습니다.
- 원본 데이터가 없으므로, 이 저장소는 동일 수치를 재산출하는 재현 저장소가 아니라 분석 설계·전처리·해석 과정을 검토하는 포트폴리오 저장소입니다.

관련 기준은 [데이터 안내](../data/README.md), [재현 가이드](reproducibility.md), [발표 이미지 출처](presentation-assets.md)에서 확인할 수 있습니다.
