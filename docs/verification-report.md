# 공개 포트폴리오 검증 기준

이 문서는 특정 시점의 일회성 결과가 아니라, 저장소를 공개하기 전에 반복해서 확인할 기준을 정리합니다.

## 자동 점검

```bash
python scripts/verify_portfolio.py
```

위 스크립트는 필수 문서의 실제 추적 여부, 문제 정의 중심 README의 섹션 순서, 로컬 Markdown 링크, README 발표 이미지의 PNG 형식, 노트북의 오류·고객 단위 HTML 표·정렬형 텍스트 표·긴 탐색 출력, 자동 패키지 설치·다운로드·홈 디렉터리 쓰기 패턴, 원본 데이터 확장자와 추적 파일 크기를 점검합니다. 원본 금융 데이터가 없으므로 분석 결과를 재실행하는 검증은 포함하지 않습니다.

## 수동 점검

- README 이미지가 `docs/IBA_서호영.pptx`의 실제 슬라이드에서 온 것인지 확인
- 원본 고객 데이터·파생 데이터·대회 제공 자료가 추적 파일에 포함되지 않았는지 확인
- [재현 가이드](reproducibility.md)의 실행 한계가 README와 일치하는지 확인
- [입력 계약](../data/input-contract.md)과 [모델 근거와 검증 범위](model-validation.md)가 실제 공개 범위와 일치하는지 확인
- 팀원 이름·사진·발표자료의 외부 공개 동의와 대회 제공 자료의 재배포 권한을 확인

## 공개 전 판단

이 저장소는 완전 재현형 리포지토리가 아니라, 금융 데이터의 공개 경계를 지키며 문제 정의부터 전략 제안까지의 사고 과정을 보여주는 포트폴리오입니다.
