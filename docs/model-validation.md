# 모델 근거와 검증 범위

## 결론부터

이 공개 저장소는 비이자이익 4개 군집의 **선택 근거·해석·전략 연결**을 보여주는 포트폴리오입니다. 실제 분석 노트북에 저장된 elbow 출력과 내부 기록에는 비이자이익을 4개 군집으로 채택한 흔적이 남아 있습니다. 다만 원본 학습 데이터와 전체 실험 로그는 비공개이므로, 이 저장소만으로 최적 군집 수나 모델 성능을 완전히 재현·검증할 수 있다고 주장하지 않습니다.

## 공개 산출물만으로 확인할 수 없는 것

| 확인 불가 항목 | 이유 |
| --- | --- |
| 후보 `k`별 원시 inertia 값과 재계산 결과 | 그림은 당시의 선택 추세를 보여주지만, 원본 데이터·실행 환경이 없어 동일 수치를 재현할 수 없음 |
| silhouette·Calinski-Harabasz·안정성 검증 | 해당 지표와 반복 학습 비교 로그가 공개본에 없음 |
| 전처리 가정별 민감도 | 상한이 없는 9구간의 대체값, 로그 변환, 표준화 선택을 바꾼 비교 실험이 공개되어 있지 않음 |
| 전략 효과 | 실제 캠페인·고객 반응·전환 데이터가 없으므로 전략의 사업 효과를 측정하지 않음 |
| 예측 성능(RMSE 등) | 본 과제는 예측 모델 평가가 아니라 고객 세그먼트와 관리 방안을 제안한 과제임 |

## 포트폴리오에서의 해석 원칙

- `k=4`는 elbow 출력과 최종 발표에서 사용된 **운영 해석 단위**입니다. 통계적으로 유일한 정답이라는 뜻은 아닙니다.
- 군집별 수치와 전략은 실제 최종 발표자료에 남아 있는 범위에서만 인용합니다.
- 실행 성과를 대신 주장하지 않고, 후속 검증에 필요한 [실행·평가 설계](execution-measurement.md)를 별도 문서로 구분합니다.

원본 데이터와 합법적인 실험 로그를 공개할 수 있게 된다면, 후보 `k`별 지표, random seed, 전처리 버전, 안정성 비교, 군집 프로파일을 같은 시점에 추가하는 것이 우선입니다.
