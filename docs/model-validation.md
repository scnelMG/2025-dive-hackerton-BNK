# 모델 근거와 검증 범위

## 결론부터

이 공개 저장소는 비이자이익 4개 군집의 **선택 근거·해석·전략 연결**을 보여주는 포트폴리오입니다. 프로젝트 내부 회의록에는 엘보우 기준으로 4개 군집을 채택한 기록이 남아 있습니다. 다만 원본 학습 데이터와 엘보우 원본 그래프·수치표는 공개하지 않으므로, 이 저장소만으로 최적 군집 수나 모델 성능을 완전히 재현·검증할 수 있다고 주장하지 않습니다.

## 공개 산출물만으로는 확인할 수 없는 것

| 확인 불가 항목 | 이유 |
| --- | --- |
| 후보 군집 수별 비교 과정 | 엘보우 채택 기록은 있으나, 후보 `k`별 원본 그래프·수치표가 공개 저장소에 없음 |
| inertia·silhouette 등 정량 지표 | 원본 데이터와 당시 실험 로그가 비공개이며, 공개본에는 inertia 수치·silhouette 표가 없음 |
| 상관계수의 원본 표·표본 수·유의확률 | 내부 회의록에는 결론값만 남아 있고, 공개본에 원본 상관 행렬과 산출 로그가 없음 |
| 재학습 안정성·대안 알고리즘 비교 | 동일 입력으로 반복 학습할 환경과 비교 실험 기록이 없음 |
| 예측 성능(RMSE 등) | 본 프로젝트는 예측 모델 평가가 아니라 고객 세분화·전략 제안 과제이므로 해당 지표를 산출하지 않음 |

## 포트폴리오에서의 해석 원칙

- 4개 군집은 엘보우 기준으로 채택했지만, “통계적으로 유일한 정답”이 아니라 최종 발표에서 사용한 **전략 설계용 고객 구분**으로 읽습니다.
- 군집별 수치와 전략은 실제 최종 발표자료에 있는 값만 인용합니다.
- 원본 데이터·실험 로그가 복원되기 전까지 모델 선택의 정량적 우수성을 추가로 주장하지 않습니다.

향후 원본 실험 기록을 공개할 수 있게 되면 후보 `k`, 각 지표, 랜덤 시드, 전처리 버전, 군집별 프로필을 같은 표에 추가하는 것이 가장 우선입니다.
