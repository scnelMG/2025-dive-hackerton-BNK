# 비공개 입력 계약

## 목적

이 문서는 원본 금융 고객 데이터를 공개하지 않고도, 분석 노트북이 어떤 입력을 기대하는지 설명합니다. 예시 행이나 합성 고객 데이터는 포함하지 않습니다. 임의의 값으로 만든 샘플이 실제 분석 결과처럼 오해될 가능성을 피하기 위해서입니다.

## 필요한 파일

| 분석 단계 | 기대 파일 | 역할 |
| --- | --- | --- |
| 전처리·군집화 | `data/hacktho_FF.csv` | 대회 제공 원본 입력 |
| 비이자이익 분석 | `data/hacktho_FF_final.csv` | 전처리·군집화 후 분석용 입력 |
| 이자이익 분석 | `data/hacktho_FF_final.csv` | 대출 상품별 세부 탐색용 입력 |

## 공개 가능한 스키마 수준

노트북 코드에 나타난 컬럼은 다음 범주로 사용됩니다.

- 고객 프로필: 연령대, 성별, 지역, 고객등급, 직업, 가입 기간
- 대출: 원화대출잔액, 주택담보·전세·소액·서민·기업 대출 구간
- 예금·비이자상품: 예금 구분, 펀드, 방카슈랑스, 신용·체크카드 거래 구간
- 채널·관계: 모바일·오픈뱅킹, 급여이체, 자동이체, 창구 방문, 이체·ATM 이용 구간
- 분석 결과: 비이자수익 군집, 이자수익 군집

원본 데이터 사전의 재배포 권한이 확인되지 않아 전체 필드 정의·코드값 표는 공개하지 않습니다. 실제 데이터 접근 권한이 있는 경우에만 대회 제공 데이터 사전과 [전처리 및 군집화 노트북](../notebooks/1.전처리_및_군집화.ipynb)을 함께 확인해야 합니다.

## 재현 범위

이 계약은 파일명·분석 흐름·입력 범주를 설명할 뿐, 결과 재현을 보장하지 않습니다. 당시 의존성 lockfile, 원본 데이터, 군집 수 선택 실험 기록은 공개본에 보존되지 않았습니다. 자세한 한계는 [재현 가이드](../docs/reproducibility.md)와 [모델 근거와 검증 범위](../docs/model-validation.md)를 참고하세요.
